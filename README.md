# Школа доброй магии — фонд «Правмир»

Адаптивная вёрстка акции по предоставленному макету Figma и архиву «Материалы лендинга». Это локальная демонстрационная версия: платежи и отправка писем не подключены.

## Как посмотреть

1. Откройте эту папку в Visual Studio Code.
2. В меню выберите **Терминал → Создать терминал**.
3. Выполните `npm start`.
4. Откройте **http://127.0.0.1:4173**. Терминал оставьте открытым.

Нужен Node.js 20 или новее. Устанавливать пакеты через `npm install` не требуется. На этом Mac можно запустить и без установки Node.js: в терминале этой папки выполните:

```sh
/Users/angelina_finkel/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node server.mjs
```

Остановить предпросмотр: Ctrl+C. Если порт занят: `PORT=4174 npm start`, затем открыть http://127.0.0.1:4174.

## Где вносить правки

| Файл | Содержимое |
| --- | --- |
| `index.html` | Постоянные блоки страницы и тексты |
| `styles.css` | Цвета, размеры, адаптив, анимации |
| `data.js` | Вопросы, ответы, факультеты, матрица баллов |
| `app.js` | Смена экранов, истории, окна, демонстрационная форма и шеринг |
| `config.js` | Адрес акции, документы фонда, готовые файлы подарков и карточек |
| `assets/` | Изображения и шрифты |
| `app.bundle.js` | Готовый файл для браузера; собирается автоматически |

После правок в `app.js`, `data.js` или `config.js` выполните `npm run build`, затем обновите страницу. Изменения HTML/CSS видны после обычного обновления. Не редактируйте `app.bundle.js` вручную — следующая сборка перезапишет его.

## Что работает

- Закреплённый хедер с фоном при прокрутке и якорной навигацией.
- Появление совы и текста, раскрытие письма. Письмо, вступление, вопросы, размышления шляпы и результат последовательно заменяют друг друга в одном блоке.
- Мобильное письмо из трёх частей с растягивающейся по высоте серединой.
- Семь вопросов, баллы +3/+1, возврат назад, сохранение выбранных ответов, секретный вопрос при разнице двух лидеров не больше двух баллов, четыре результата.
- Карточки факультетов переключают историю выше и прокручивают к ней.
- Демонстрационная форма открывает окно благодарности. Имя и факультет берутся из формы; результат теста на сертификат не влияет.
- Шеринг результата теста и общее приглашение. В окне подарков кнопка «Пригласить друга» всегда открывает общее приглашение.
- Предварительные PNG-карточки генерируются в браузере и скачиваются. После передачи финальных карточек достаточно заполнить `shareImages` в `config.js`.
- Ссылки шеринга ВК, ОК, Telegram появляются после задания публичного адреса. MAX: копирование приглашения для вставки в чат. Системное меню других приложений — если доступно в браузере.
- Автоматическая карусель партнёров с паузой при наведении/фокусе.
- Клавиатурный фокус, диалоги с Escape, режим уменьшенной анимации.

## Что нужно добавить перед публикацией

- Тексты и фотографии трёх оставшихся историй. Сейчас в них явно обозначены заглушки.
- Общую иллюстрацию подарков для правой части блока пожертвования.
- Четыре окончательных шаблона сертификата и правило размещения имени.
- **Один ZIP со всеми обоями**. В `config.wallpapersZip` указывается один файл.
- Пять финальных карточек шеринга: общее приглашение и четыре факультета. Сейчас используются предварительные карточки из имеющихся элементов.
- Публичный адрес в `config.publicUrl`; абсолютные `og:url` и `og:image` в HTML. Для разных превью факультетов в соцсетях потребуются отдельные публичные страницы с соответствующими Open Graph метаданными: обычная ссылка не передаёт сгенерированную PNG автоматически.
- Реальную форму через iframe, подтверждение платежа, выдачу именных сертификатов и рассылку — см. `HANDOFF.md`.
- Редакторское согласование финальных текстов и проверку платёжной интеграции после её подключения.

Названия/описания программ и переходные тексты, для которых не удалось получить полный контекст из Figma, требуют редакторской сверки с утверждённым макетом. Структура страницы сохранена.

## Правило равенства в тесте

В документе определён дополнительный вопрос для двух лидеров, но не определён выбор пары при равенстве трёх или четырёх факультетов. В этой версии при равенстве общих баллов приоритет определяется вкладом последнего ответа, затем предыдущих. Это детерминированное допущение можно изменить в `getOutcome()` в `data.js`. Из выбранной пары побеждает факультет, за который пользователь ответил в секретном вопросе.

## Проверки

`npm test` — проверка матрицы и всех 16 384 сочетаний ответов, секретных вопросов, пересчёта при изменении ответа и некорректного ввода.

В браузере проверены desktop 1440 px, mobile 320/390 px и планшет 768 px: раскрытие письма, прохождение теста, секретный вопрос, переключение шеринга и скачивание PNG, окно подарков и независимость факультета сертификата от результата теста. Ошибок JavaScript в проверенных сценариях не обнаружено. Подробности — `QA.md`.

## GitHub и дальнейшее размещение

Проект не привязан к конкретному хостингу. Его можно загрузить в новый репозиторий GitHub целиком; файл `.gitignore` исключает служебные файлы.

Для правок: измените код → при необходимости `npm run build` → проверьте → сделайте commit → push в GitHub. Изменения появятся в репозитории. Чтобы они автоматически появлялись на опубликованном сайте, разработчик должен отдельно настроить развёртывание из GitHub на выбранный сервер.

Для статического хостинга достаточно `index.html`, `styles.css`, `app.bundle.js` и папки `assets/`. Серверный файл `server.mjs` нужен только для локального просмотра. Все пути относительные, поэтому подходит и размещение в подпапке.

Шрифты и иллюстрации предоставлены заказчиком. Исходный архив не изменялся; для сайта подготовлены облегчённые копии изображений WebP.
